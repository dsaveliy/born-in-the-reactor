**Жанр:** 2D шутер с элементами выживания (survival)  
**Сеттинг:** Постапокалиптический мир (альтернативная реальность Чернобыля/Гомеля)  
**Целевая платформа:** Кроссплатформенный (Windows, macOS, Linux)  
**Технологический стек:** Python 3.10+, Pygame, JSON, SQLite  
**Статус проекта:** Завершённый учебный проект

## Краткое описание

«Born In The Reactor» — это мрачный 2D шутер, разработанный в рамках учебной практики. Действие происходит в альтернативной реальности, где последствия чернобыльской катастрофы оказались катастрофичнее. Игроку предстоит пройти через 4 уровня: руины Гомеля, заражённую больницу, заброшенную военную базу и финально сразиться с мутировавшим боссом в самом сердце реактора.

Проект демонстрирует применение принципов ООП, архитектурных паттернов и современных инструментов разработки.

## Ключевые особенности

- **Атмосферный сеттинг:** Мрачная постапокалиптическая эстетика, вдохновлённая играми Hotline Miami и Darkwood
- **Динамичный геймплей:** Система стрельбы типа hitscan, три вида оружия с уникальными характеристиками
- **Продуманная архитектура:** Чистая система состояний (State Machine), data-driven дизайн уровней
- **Полноценный интерфейс:** Главное меню с анимированным персонажем, экраны настроек, статистики и справочника
- **Простой ИИ врагов:** Враги обладают базовым ИИ с состояниями блуждания, преследования и атаки

## Управление

- **Движение:** WASD или стрелки
- **Стрельба:** Левая кнопка мыши (наведение мышью)
- **Смена оружия:** Клавиши 1, 2, 3
- **Перезарядка:** R

## Технические детали реализации

### Архитектура проекта

Проект построен на системе конечных автоматов (State Machine), где каждое игровое состояние представляет собой изолированный модуль с собственной логикой:

### MainMenuState
Главное меню с интерактивным анимированным персонажем, которым можно управлять для навигации по пунктам меню. Реализована система подсказок при наведении на элементы интерфейса.

### GameplayState
Ядро игрового процесса, содержащее всю основную логику: управление персонажем, систему боя, искусственный интеллект врагов, физику столкновений и механику взаимодействия с окружением.

### SettingsState
Экран настроек с возможностью регулировки громкости музыки и звуковых эффектов, изменения параметров геймплея и графических опций. Все настройки сохраняются между сеансами игры.

### StatsState
Система статистики и таблица рекордов, реализованная на базе SQLite. Позволяет отслеживать прогресс игрока, сохранять лучшие результаты и анализировать игровые показатели.

### HelpState
Интерактивный справочник с подробным руководством по игровой механике, управлению и сюжету. Реализована система категорий и удобная навигация по разделам помощи.

## Система стрельбы (Hitscan)

В проекте реализована оптимизированная система стрельбы по технологии hitscan, которая исключает необходимость симуляции физики снарядов. При выстреле мгновенно вычисляется луч от оружия до точки прицеливания и проверяется пересечение с врагами на его пути. Это решение обеспечивает высокую производительность и точность попаданий, что критически важно для динамичного шутера.

## Искусственный интеллект врагов

Враги используют трехсостоянийный конечный автомат, что обеспечивает разнообразное и предсказуемое поведение:

- **Блуждание** - случайное перемещение по карте при отсутствии видимости игрока
- **Преследование** - движение к игроку при его обнаружении с обходом препятствий
- **Атака** - нанесение урона при приближении на критическую дистанцию

Система проверки видимости учитывает препятствия на пути, делая поведение врагов более реалистичным.

## Data-Driven дизайн уровней

Архитектура уровней построена на принципах data-driven подхода. Каждый уровень описывается в отдельном JSON-файле, который содержит:

- Фоновые текстуры и декорации
- Карту коллизий и непроходимых областей
- Точки спавна врагов с указанием их типов
- Зоны перехода между уровнями
- Расположение интерактивных объектов и collectibles

Такой подход позволяет легко создавать и редактировать уровни без изменения программного кода, а также обеспечивает гибкость в дизайне игрового пространства.

## Визуальные эффекты

Система визуальных эффектов реализована с использованием альфа-канала и постепенного затухания. Эффект получения урона представляет собой динамическое красное затемнение экрана, интенсивность которого плавно уменьшается со временем. Это создает ощущение воздействия и обратной связи для игрока без перегрузки интерфейса дополнительными элементами.
